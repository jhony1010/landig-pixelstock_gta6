# Pixel Stock — GTA VI Landing V3.2

Abrir `index.html` en el navegador. Archivos separados: `index.html`, `styles.css`, `script.js`, carpeta `assets`.

## Cambios
- Selector Standard/Ultimate sincronizado en las tarjetas y calculadora.
- Precios de referencia COP: Standard 227.000/155.000; Ultimate 295.000/210.000.
- Calculadora prioriza «¿Cuánto planeas jugar?» y muestra selección, plazo y comparación.
- Consultas de modalidades PSN informativas; **no procesa alquiler ni venta de cuentas**.
- Checkout de consolas preservado, con recargos de demostración y solicitud por WhatsApp.
- Se conservan hero, animaciones, imagen oscura del comparador, cookies y footer.

## Publicación
Verificar derechos de uso de imágenes, contenido de las ediciones, precios, condiciones de pagos, autorización comercial de productos y políticas de privacidad antes de publicar.

## V3.3
Se simplificó exclusivamente el comparador: se eliminaron la tarjeta de pago único y la franja de diferencia, y se destacó el presupuesto mensual. Se mantienen las selecciones, el total, la consulta informativa y todas las demás secciones. Los accesos PSN no están disponibles para contratación comercial.
